# KT_Data_Support
Приложение-помощник для настольной игры "Warhammer 40000: Kill Team 2024 ed.".

Приложение на Windows для просмотра необходимой информации о командах, оперативниках и их вооружении. Поддерживаются операции просмотра, добавления, изменения и удаления информации об игровых объектах. Вводимые данные проверяются на соответствие игровым правилам.
<img width="1089" height="597" alt="image" src="https://github.com/user-attachments/assets/5b5af1ff-68bc-4b90-a806-d2f9a01f11bb" />

Вся информация об игровых элементах содержится в соответствующих классах: 
Team - используется для хранения всех необходимых сведений о команде;
<img width="398" height="450" alt="image" src="https://github.com/user-attachments/assets/294e7a61-fbdc-47e4-8f24-8452040b2a45" />
Operative - хранит характеристики конкретного оперативника;
<img width="400" height="450" alt="image" src="https://github.com/user-attachments/assets/2984ea12-2ddd-47c7-8a1d-38ecc935131f" />
Weapon - хранит всю информацию о конкретном вооружении.
<img width="401" height="449" alt="image" src="https://github.com/user-attachments/assets/76ec5f27-e7a1-4408-bdd4-100ae84194b8" />

Для просмотра данных требуется выбрать искомый объект в правой половине окна программы. Слева располагаются игровые объекты, справа - информация о них. В нижнем правом углу находится поле, куда выводится более подробная информация (например игровые правила или стратагемы).
<img width="531" height="548" alt="image" src="https://github.com/user-attachments/assets/0e678c9d-96ae-419f-8fc9-5954176a7ad5" />

Для Остальных операций служит левая часть окна программы. Слева сверху выбирается тип операции (добавление, обновление или удаление), справа сверху располагается группа полей и кнопок, куда требуется вводить необходимую информацию. В нижнем углу будет отображаться результат операции
<img width="540" height="558" alt="image" src="https://github.com/user-attachments/assets/55c6e03a-da43-4259-9c40-fff757fcc355" />


Для запуска приложения требуется запустить файл ".\bin\Debug\KT_Data_Support_main.exe".
